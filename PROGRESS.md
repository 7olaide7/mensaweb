## Build and preview
- Portable output (relative links, CSS/JS embedded): `python3 build.py`
- Production clean-URL output (root-relative links and external assets): `python3 build.py --clean`
- Local preview after the portable build: `python3 -m http.server 8000`
- Deploy the generated site at the domain root. If using the clean-URL build, configure the host to serve each directory's `index.html` and serve `404.html` as the not-found page.
